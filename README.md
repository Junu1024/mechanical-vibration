# 기계진동학 (우주구조)

기계진동학 과목의 학습과 시험 대비 기록을 모아 두는 저장소입니다.

## 폴더 구조

| 폴더 | 내용 | 파일 이름 규칙 |
|---|---|---|
| `강의자료/` | 강의자료(PDF, Word 등)에서 추출한 텍스트와 수식 | `기계진동학_원본파일명.md` |
| `위키/` | 질문과 답변에서 정리한 핵심 개념과 공식 | `기계진동학_YYYY-MM-DD.md` |
| `로우/` | 질문과 답변 대화 기록 원문 | `YYYY-MM-DD.md` |
| `로우/_태그목록.md` | 대화 기록의 태그 색인 (예전 내용 검색용) | 한 줄씩 추가 |

## 작성 규칙

- 날짜 형식은 `YYYY-MM-DD`
- 같은 이름의 파일이 있으면 덮어쓰지 않고 맨 아래에 이어서 추가
- 수식은 LaTeX(`$...$`, `$$...$$`)로 쓰고 기호의 뜻과 단위를 함께 적기

## 로컬 폴더와 동기화

이 저장소는 `C:\Users\user\Desktop\기계진동학` 폴더와 같은 구조입니다.
GitHub Desktop 등으로 이 저장소를 clone한 뒤 기존 md 파일을 같은 폴더에 복사하고 commit / push 하면 됩니다.
